# FPS 丧尸 AI 与受击

> 范围：丧尸角色、状态树 AI 攻击、部位物理材质、爆头音效、丧尸受击事件。玩家侧受伤见 `fps-03`。

## 结论

丧尸 AI 用的是**引擎状态树（StateTree）**，不是行为树（BehaviorTree）。这条线上「打击感」的核心是**部位物理材质 → 音效映射**：

1. 先给丧尸的头 / 手 / 脚分别设置**物理材质**（`Content/FPS/Code/Physics` 下 10 个资产）；
2. 命中时读被击中的物理材质，判断部位；
3. 头部命中播放特殊音效，形成「爆头」反馈。

这套做法的价值是：**同一颗子弹打到不同部位自动给出不同音效**，不需要为每个部位单独做碰撞体或伤害分支。

## 反例与坑

**坑 1：状态树 ≠ 行为树**

`3e29c97` 用的是**状态树**。两者在 UE 里是不同系统（StateTree 是较新的、数据驱动的方案）。查资料时如果按 BehaviorTree 搜，会得到完全对不上的 API 与节点名。

**坑 2：物理材质不是物理资产**

`Code/Physics` 里是**物理材质（Physical Material）**，用于给命中面打标记（表面类型 / 音效），不是 `PhysicsAsset`（布料、刚体那种）。两者中文都叫「物理资产」，容易混。
